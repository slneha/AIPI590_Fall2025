# Adversarial Patch Experiments: My Tests

### Overview
This repository contains experiments based on the **adversarial patch tutorial** derived from the original `tutorial10` (ResNet34 + TinyImageNet) setup.  
The primary goal was to explore how **merged patches** (such as 4×1 strips, 2×2 tiles, and alpha blends) behave compared to standard single-class adversarial patches.
